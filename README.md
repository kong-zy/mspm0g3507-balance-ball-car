# 车载平衡滚球运动控制系统（电赛 H 题）

基于 **TI MSPM0G3507**（主控）+ **嘉楠 K230**（视觉）的平衡滚球小车控制系统，全国大学生电子设计竞赛 H 题控制类作品。

## 功能

- **循迹行驶**：8 路灰度传感器检测黑线，沿赛道跑一整圈并自动识别终点停车
- **滚球控制**：K230 视觉识别钢球位置，舵机摆杆控制钢球在 ±5cm 内往返并稳定保持
- **实时图传**：K230 CH0 通道 H.264 编码，RTSP 推流到上位机

## 系统架构

| 模块 | 器件 | 接口 |
| --- | --- | --- |
| 主控 | TI MSPM0G3507（Cortex-M0+，80MHz） | CCS + SysConfig + DriverLib |
| 视觉 | 嘉楠 K230（庐山派，CanMV MicroPython） | UART2，115200 8N1 |
| 循迹 | 感为 8 路数字灰度传感器 | GPIO 直读（黑线低电平） |
| 测速 | 编码器 ×2（正交解码） | 外部中断计数 |
| 驱动 | 直流电机 ×2 | TimerA1 PWM + 方向 GPIO |
| 摆杆 | 舵机 ×2 | PWM，脉宽 750~2250us |
| 显示 | SSD1306 OLED | 软件 I2C，地址 0x3C |
| 姿态 | JY901 六轴（比赛版禁用） | UART1，9600 |

## 通信协议（K230 ↔ 主控）

- 串口：UART2，115200，8N1，TX/RX 交叉共地
- 帧格式（ASCII 行协议，`\r\n` 结尾，异或校验）：

```
$BALL,SEQ,POS10,PIXEL_X,VALID,QUALITY*CS
```

| 字段 | 含义 |
| --- | --- |
| SEQ | 帧序号，0~9999 循环 |
| POS10 | 钢球位置，单位 0.1mm，范围 ±1250 |
| PIXEL_X | 钢球像素横坐标 |
| VALID | 是否有效（丢球为 0，主控不得闭环保旧值） |
| QUALITY | 识别质量分 0~100 |
| CS | 载荷逐字节异或校验，两位大写十六进制 |

- 接收链路：UART 中断只收字节 → 128B 环形缓冲 → 主循环按行解析（单次 ≤64B）；150ms 无新帧判视觉离线，摆杆回中位保护
- 附带 PING/PONG 心跳帧、`@K230/@ACK` 压力测试帧，便于单独联调

## 控制算法

**循迹（双环）**

- 3ms 位置外环：PD 控制（Kp=1.0，Kd=1.5，无积分，避免弯道积分累积）
- 10ms 速度内环：增量式 PI（Kp=150，Ki=12，PWM 限幅 ±7000）
- 停车即清 PI 状态，防止下次起步跑偏；终点横线多帧累计识别后停车

**滚球（分阶段 PD）**

- MOVE / BRAKE / CAPTURE / HOLD 四阶段独立参数与限幅
- P 项使用 80ms 预测位置（补偿视觉/串口/舵机延迟），D 项直接使用视觉速度（避免目标跳变微分冲击）
- 非对称变化率：加速 3us/10ms，制动 15~20us/10ms，防超调
- 条件积分 + 滞回切换，避免视觉抖动引起控制器反复切换

## 目录结构

```
.
├── empty/               # MSPM0G3507 主控工程（CCS）
│   ├── Application/     # 应用层：状态机、循迹、滚球控制
│   ├── Hardware/        # 驱动层：电机、编码器、K230、OLED 等
│   ├── empty.syscfg     # SysConfig 外设配置
│   └── targetConfigs/   # 烧录调试配置
├── K230/                # 视觉端 MicroPython 程序
│   ├── main.py          # 主程序（识别 + 组帧发送 + 图传）
│   └── K230.py          # 视觉库
├── Makefile             # 根目录构建入口
└── .gitignore
```

## 构建与烧录

1. 用 CCS（Theia 版）导入 `empty/` 目录，`empty.syscfg` 会自动生成外设初始化代码
2. 编译后通过 `targetConfigs/MSPM0G3507.ccxml` 烧录到主控板
3. 将 `K230/` 下程序部署到 K230 开发板（CanMV IDE 或 SD 卡）
4. 上电顺序：先 K230 后主控，或同时上电（主控侧有离线保护，不影响安全）

> **注意**：`K230/main.py`、`K230/K230.py` 中的 Wi-Fi 账号密码为占位符，现场使用前需填入真实 2.4GHz 热点信息；Wi-Fi 配置错误不影响视觉与串口运行。
